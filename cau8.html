Lý thuyết JavaScript 1. JavaScript là gì? Dùng để làm gì trong thiết kế web? JavaScript (JS) là ngôn ngữ lập trình bậc cao, thông dịch (interpreted), động, được chạy trực tiếp trên trình duyệt (và cả trên server nhờ Node.js). Nó cùng với HTML và CSS tạo thành bộ ba nền tảng của web: • HTML: cấu trúc, nội dung trang • CSS: giao diện, hiển thị • JavaScript: hành vi, tương tác Vai trò trong thiết kế web: • Thao tác DOM: thay đổi nội dung, style, cấu trúc trang mà không cần tải lại. • Xử lý sự kiện: click, nhập liệu, cuộn trang, di chuột... • Kiểm tra dữ liệu form (validation) phía client. • Gửi/nhận dữ liệu bất đồng bộ với server (AJAX, fetch, API). • Tạo hiệu ứng, animation, slider, menu động, biểu đồ. • Xây dựng ứng dụng web hoàn chỉnh (React, Vue, Angular), ứng dụng server 2. JavaScript có phải ngôn ngữ đơn luồng không? Có. JavaScript là ngôn ngữ đơn luồng (single-threaded): tại một thời điểm, engine chỉ thực thi một tác vụ trên một call stack. Tuy vậy, JS vẫn xử lý được tác vụ bất đồng bộ (timer, gọi API, đọc file) nhờ Event Loop: 1. Tác vụ bất đồng bộ được giao cho môi trường bên ngoài (Web APIs của trình duyệt hoặc libuv của Node.js). 2. Khi hoàn thành, callback được đưa vào hàng đợi (callback queue / microtask queue). 3. Event Loop chỉ đẩy callback vào call stack khi stack đang rỗng. Nhờ đó JS không bị "treo" khi chờ tác vụ chậm. Nếu cần chạy song song thật sự, có thể dùng Web Workers. js console.log("1"); setTimeout(() => console.log("2"), 0); console.log("3"); // Kết quả: 1, 3, 2 ________________________________________ 5. Toán tử delete có tác dụng gì? Tác dụng: xóa một thuộc tính khỏi object. Trả về true nếu xóa thành công (hoặc thuộc tính không tồn tại), false nếu không xóa được (thuộc tính non-configurable; ở strict mode sẽ ném TypeError). js const user = { name: "An", age: 20 }; delete user.age; console.log(user); // { name: "An" }
